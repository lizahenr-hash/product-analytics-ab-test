# Product Analytics: A/B Test

## Описание проекта
Анализ A/B-теста в мобильной игре Cookie Cats с использованием Python, SQL и PostgreSQL.

## Цель
Сравнить удержание игроков и игровую активность при размещении ворот на уровнях 30 и 40.

## Инструменты
- Python, Pandas
- SQL, PostgreSQL
- Jupyter Notebook
- Анализ A/B-тестов и проверка статистической значимости
